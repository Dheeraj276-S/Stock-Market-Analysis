# 📈 Stock Market Analysis using Python, MySQL & Power BI

## Problem Statement

Stock market prices change continuously, making it difficult for investors and analysts to manually monitor market trends and evaluate stock performance. This project aims to automate the process of collecting historical stock market data, storing it in a MySQL database, analyzing it using Python, and presenting meaningful insights through an interactive Power BI dashboard. The solution helps users compare multiple stocks, monitor trading activity, and support data-driven investment decisions.

## Objectives

- Fetch historical stock market data using the Alpha Vantage API.
- Store stock data in a MySQL database.
- Clean and preprocess the data using Python.
- Analyze stock price trends and trading volume.
- Create an interactive Power BI dashboard.
- Compare the performance of multiple stocks.

## Technologies Used

- Python
- Pandas
- Requests
- PyMySQL
- MySQL
- Power BI
- Alpha Vantage API
